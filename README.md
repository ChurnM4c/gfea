# gfea

A small product list built with Next.js and a GraphQL backend.

## Start in the browser (no setup needed)

Use the link from your invitation, or on GitHub click **Code → Codespaces → Create codespace on …** while the branch of your exercise is selected.

You need a GitHub account. Backend and frontend start automatically and the app opens in a preview tab. Don't run `npm start` yourself in a Codespace, the servers are already running.

When you are done, delete the Codespace on https://github.com/codespaces so it doesn't use up your free quota.

## Start locally

Requires Node.js 24.

```bash
npm start
```

## URLs

| What     | URL                               |
| -------- | --------------------------------- |
| App      | http://localhost:3000             |
| GraphiQL | http://localhost:3000/graphql     |

In a Codespace, open the **Ports** tab and use the address of port 3000 instead of `http://localhost:3000`.
