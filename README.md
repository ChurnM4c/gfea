# gfea

A small product list built with Next.js and a GraphQL backend.

## Start in the browser (no setup needed)

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/ChurnM4c/gfea)

You need a GitHub account. Installing the dependencies takes a few minutes the first time. When it is done, backend and frontend start automatically and the app opens in a preview tab.

## Start locally

Requires Node.js 24.

```bash
npm start
```

## URLs

| What     | URL                               |
| -------- | --------------------------------- |
| App      | http://localhost:3000             |
| GraphiQL | http://localhost:3000/graphql     |

In a Codespace, open the **Ports** tab and use the address of port 3000 instead of `http://localhost:3000`.
